Font Awesome Free 7.3.1 — vendored icon copies.

Source:  https://cdn.jsdelivr.net/npm/@fortawesome/fontawesome-free@7.3.1/svgs/
Fetched: 2026-11-17

Icons (the .svg files here): CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
Package code: MIT. Fonts: SIL OFL 1.1 (unused — these are inlined paths, not a webfont).

Every file is an unmodified copy and keeps Fonticons, Inc.'s embedded attribution
comment; do not strip it. The <path> is pasted into a template from here, and each file
carries its own viewBox — copy both together. Edit nothing in this directory by hand.

7.3.1 (latest) is deliberate rather than the version that matches the Penpot file. The
drawings come from a 2020-component Font Awesome 6 Free library, and six glyphs changed
canvas between 6 and 7: arrow-left 448->512 wide, image 512->448, file-pdf 512->576,
chevron-down 512->448, boxes-stacked 576->512, cart-shopping 576->640. Those six sit a
little wider or narrower than the frame; the other seventeen keep their proportions.

The set is the 23 glyphs that appear on Penpot Page 3, tallied by layer name:

  solid (22)   plus, trash, xmark, arrow-left, image, file-pdf, arrow-up-wide-short,
               filter, eye, chevron-down, magnifying-glass, clipboard-list,
               chevron-left, chevron-right, circle-exclamation, receipt,
               boxes-stacked, users, user-plus, box-open, cart-shopping,
               arrow-right-from-bracket
  regular (1)  calendar-days

calendar-days is Regular because the design's date field uses the Regular style; every
other icon is Solid. To add an icon, fetch it from the same base URL at the same version
under the same style directory.
